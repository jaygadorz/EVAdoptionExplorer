# EV Adoption Explorer 🚗⚡

This repository contains my side project focused on exploring **Electric Vehicle (EV) Adoption** through descriptive analytics. The goal is to provide a platform that demonstrates how data can be hosted, transformed, and visualized across different technologies.

---

## 📖 Chapters

1. **Understand overall EV Adoption**  
   Gain insights into global adoption trends and growth patterns.

2. **Discover where adoption is strongest**  
   Identify regions and countries leading the EV revolution.

3. **Identify market segments driving adoption**  
   Explore demographics, industries, and consumer groups fueling adoption.

---

## 🎯 Project Aim

The project showcases a different platform to host **basic descriptive analytics**, combining cloud services, analytics engineering, and visualization tools.

---

## ⚙️ Tech Stack

- **Backend Operations**: Azure Data Factory, Azure SQL Server  
- **Data Cleaning & Transformation**: Python (Pandas, reusable functions)  
- **Frontend UI**: PowerApps, HTML, Chart.js
